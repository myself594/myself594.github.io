# 一日三餐恋

一个为情侣设计的美食记录与分享网站。

## 功能

- 首页 - 查看概览信息
- 用餐记录 - 记录每日用餐
- 纪念日管理 - 管理重要纪念日
- 情侣菜谱 - 收藏喜爱的菜谱
- 个人中心 - 管理个人信息
